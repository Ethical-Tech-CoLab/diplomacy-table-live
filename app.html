AI Providers

Register OpenAI-compatible AI providers. Use the provider name as provider on a session party to route that party's turns through GitHub Models, OpenAI, Azure OpenAI, Together, Groq, etc. The endpoint should be the base URL (without /v1/...) — the ollama twin appends /v1/chat/completions. For security in production, use apiKeyEnvVar and set the env var on the server instead of pasting the key here.
